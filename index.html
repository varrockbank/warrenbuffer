Blazing fast and minimalist text interface, Inspired by Vim and the terminal:

The core is a rendering engine of monospace plaintext in grid-layout.

As a text buffer, Buffee is efficient by maintaining a viewport with a small DOM footprint. Performance does not degrade with the length of the text. In fact, this project descend from an initiative to inspect massive distributed server logs in browser, distilling breakthroughs in that space.

To maximize performance, the implementation tightly couples text editing capabilities with the rendering and text buffering core.

Credit to the wizards of V8. Compactness was feasible with V8 arrays being viable as a text buffer. Compare with complex structures, plural, needed by native editors, e.g. piecetable. Content and syntax aware considerations aside, Buffee rivals the performance of native text editors.

Combinator-oriented extension system, adopting Neovim's modular ethos

Buffee is designed to be hackable with a minimal but powerful API: API cheatsheet

The extension system is with combinators - functions that take as input a buffee instance and return a buffee instance with more functionality. This is novel because, unlike other text editors, Buffee is just a callable function that you can readily access and reprogram.

The Neovim paradigm is to be modular, consisting of many single-purpose extensions. Buffee follows the same philosophy, having a lightweight core with extensions that can be chained and combined, hence combinator.

TUI

TUI mode ship as a combinator. As notcurses brings browser bling to the terminal, Buffee completes the circle by ushering in 20th century paradigms to the modern web.
