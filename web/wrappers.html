Wrappers

Framework wrappers for Buffee. Use these to integrate Buffee into your preferred framework.

React

wrappers/react.jsx

import { BuffeeEditor } from './react.jsx';

function App() {
  const editorRef = useRef(null);

  useEffect(() => {
    if (editorRef.current) {
      editorRef.current.Model._ = ['Hello, World!'];
      editorRef.current.View.render();
    }
  }, []);

  return <BuffeeEditor ref={editorRef} h={10} theme="eva" />;
}

Svelte

wrappers/svelte.svelte

<script>
  import BuffeeEditor from './svelte.svelte';
  let editor;

  function handleReady(e) {
    editor = e.detail;
    editor.Model._ = ['Hello, World!'];
    editor.View.render();
  }
</script>

<BuffeeEditor h={10} theme="eva" on:ready={handleReady} />

Vue

wrappers/vue.js

<script setup>
import BuffeeEditor from './vue.js';

function handleReady(editor) {
  editor.Model._ = ['Hello, World!'];
  editor.View.render();
}
</script>

<template>
  <BuffeeEditor :h="10" theme="eva" @ready="handleReady" />
</template>

Props

All wrappers support these props:

h            Number      Fixed number of visible lines
w            Number      Fixed number of text columns
s            Number      Spaces per tab (default: 4)
theme        String      Theme name (e.g., 'eva', 'nord', 'gruv')
showGutter   Boolean     Show line numbers (default: true)
gutterRight  Boolean     Position gutter on right side (default: false)
showStatus   Boolean     Show status bar (default: true)
statusTop    Boolean     Position status bar at top (default: false)
lines        String[]    Initial content as array of lines (pre-sanitized)
combinators  Function[]  Array of combinator functions to apply

Combinators

Pass combinators via the combinators prop. Combinators are applied in order.

Import combinators or load them globally via script tags:

ES Modules

import BuffeeHistory from 'buffee/combinators/history.js';
import BuffeeSyntax from 'buffee/combinators/syntax.js';

<BuffeeEditor combinators={[BuffeeHistory, BuffeeSyntax]} />

Script Tags

<script src="buffee/combinators/history.js"></script>
<script src="buffee/combinators/syntax.js"></script>

<BuffeeEditor combinators={[BuffeeHistory, BuffeeSyntax]} />

Accessing Combinator APIs

Use the onReady callback to access combinator APIs:

function handleReady(editor) {
  editor.History.undo();
  editor.Syntax.setLanguage('javascript');
}

Note: BuffeeStatusLine is applied automatically when showStatus is true. You don't need to include it in the combinators array.
