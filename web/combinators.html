Combinators

Buffee's extension system uses combinators - functions that take a buffee instance and return a buffee instance with more functionality.

You can chain and combine these extensions together. Hence, combinator.

Available Combinators

See Examples for interactive demos.

buffee.jsKeyboard/clipboard controller over buffe.js (yes, Buffee is a combinator!)
elementals.jsDOM-based UI elements in a layer above text
fileloader.jsMultiple file loading strategies for different file sizes
history.jsUndo/redo support with operation coalescing
ios.jsTouch interactions and on-screen keyboard for iOS
sanitize.jsConverts tabs to spaces and normalizes Unicode
statusline.jsUpdates status bar elements on each render
syntax.jsRegex-based syntax highlighting with incremental state caching
tui.jsTerminal UI via text manipulation
ultrahighcapacity.jsGzip-compressed chunked storage for 1B+ lines
undotree.jsTree-based undo/redo that preserves all branches
vimmotion.jsVim-style motion commands with count support

Using Multiple Combinators

Compose combinators using the decorator pattern:

const editor = BuffeeElementals(
  BuffeeSyntax(
    Buffee(container, config)
  )
)

For many combinators, use reduce to avoid deep nesting:

const combinators = [BuffeeHistory, BuffeeSyntax, BuffeeElementals]
const editor = combinators.reduce((ed, comb) => comb(ed), new Buffee(container, config))
