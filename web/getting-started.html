Getting Started

1. CSS

Include style.css for structural styles:

<link rel="stylesheet" href="style.css">

1a. Define your color theme 

<style>
.buffee {
  background-color: #282C34;
  color: #B2B2B2;
}
.buffee .buffee-zsel > div {
  background-color: #EDAD10;
}
.buffee .buffee-caret {
  background-color: #FF6B6B;
}
.buffee .buffee-rail,
.buffee .buffee-status {
  background-color: #21252B;
  color: #636D83;
}
</style>

1b. Alternatively, include pre-built theme

<link rel="stylesheet" href="themes/theme-eva.css">

Reference the theme's CSS class on your editor element:

<div class="buffee buffee-themepack1-eva" id="editor">

See more: pre-built themes.

2. Add HTML Structure from template.html

<div class="buffee" id="editor">
  <textarea class="buffee-clip" aria-hidden="true"></textarea>
  <div class="no-select buffee-pane">
    <div class="buffee-rail"></div>
    <div class="buffee-lines" tabindex="0">
      <div class="buffee-zsel"></div>
      <blockquote class="buffee-ztxt"></blockquote>
      <div class="buffee-layer-elements"></div>
      <div class="buffee-caret"></div>
    </div>
  </div>
  <div class="buffee-status">
    <div class="buffee-status-left"><span class="buffee-linecount"></span></div>
    <div class="buffee-status-right">
      Ln <span class="buffee-head-row"></span>, Col <span class="buffee-head-col"></span>
      <span class="buffee-status-divider">|</span>
      <span class="buffee-spaces"></span>
    </div>
  </div>
</div>

3. JavaScript

Buffee is a JavaScript function globally available when you include dist/buffee.min.js

<script src="dist/buffee.min.js"></script>
<script>
    // Binds to the HTML element specified earlier 
    const instance = new Buffee(document.getElementById('editor'))
    instance.Model._ = ["Hello, World!"]
    instance.View.render();
</script>

Sizing

By default, the editor auto-fits to fill parent container. Specify a dimension overrides this.

new Buffee(el, {})                  // Auto-fit (default)
new Buffee(el, { h: 20 })           // Fixed number of rows
new Buffee(el, { w: 80 })           // Fixed number of columns
new Buffee(el, { h: 20, w: 80 })    // Fixed number of rows and columns

For auto-fit to work, the container must have a defined height (e.g., height: 100% with sized parent, or explicit pixels).

See more scenarios in sizing examples.

API

Buffee exposes four namespaces:

instance.Model._          // Array of text lines
instance.View.render()    // Render after changes
instance.View.set(n)      // Scroll to line n
instance.Span.ins(lines)  // Insert at cursor
instance.Span.del()       // Delete selection
instance.Mode.i           // Edit mode: 1=write, 0=navigate, -1=read

See full API reference.
